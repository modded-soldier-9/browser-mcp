# Browser Control Server

## Overview
High-performance native Rust Model Context Protocol (MCP) server package for Browser Control. It provides standard I/O and WebSocket bridge integration between AI agent environments and Chromium-based browsers (Chrome, Brave).

## Subdirectories & Boundaries
- [src](./src/README.md): Core Rust implementation containing MCP protocol handlers, WebSocket extension bridge, sandbox validation, tool definitions, and process watchdog.
