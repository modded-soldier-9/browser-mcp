Quick Setup

Connect your assistant directly to your daily browser in 60 seconds.

  1. Extract Extension Assets Run the standalone installer to unpack the extension into ~/.browser-mcp/extension (or download the pre-built binary from GitHub Releases).
    browser-mcp install
  2. Load Unpacked Extension Open brave://extensions or chrome://extensions, toggle Developer mode ON, click Load unpacked, and select ~/.browser-mcp/extension (or %USERPROFILE%\.browser-mcp\extension on Windows).
  3. Register Native MCP Server Connect Browser MCP directly to your AI assistant. Standalone native binary with zero Node.js runtime needed:
    claude mcp add browser-mcp -- browser-mcp
    For Cursor (~/.cursor/mcp.json), Antigravity (~/.gemini/config/mcp_config.json), or Claude Desktop (macOS: ~/Library/Application Support/Claude/claude_desktop_config.json, Windows: %APPDATA%\Claude\claude_desktop_config.json): 
    {
  "mcpServers": {
    "browser-mcp": {
      "command": "browser-mcp"
    }
  }
}
  4. Verify Automation Ask your assistant in Claude Code, Cursor, Codex, or Antigravity:
    Take a screenshot of my current Chrome tab.
    Your agent captures your active tab in real time with sub-4ms CDP event dispatch. Installation verified. View examples →

Frequently Asked Questions

Everything you need to know about setup, security, and architecture.

What is Browser MCP and why was it rewritten in Rust?
Browser MCP is an open-source Model Context Protocol server that bridges AI assistants to your daily browser. It was rewritten from scratch as a standalone native Rust binary to eliminate Node.js dependencies, achieve sub-4ms cold startup, reduce idle memory to ~3.8MB, and introduce an autonomous Token Shield that protects LLM context windows from token exhaustion.
How does Browser MCP differ from Playwright MCP and legacy Agent360?
Unlike Playwright MCP, which spins up isolated headless profiles that hit bot verification and login walls, Browser MCP connects directly to the Brave and Chrome tabs you are already signed into. Compared to the legacy Agent360 Node.js implementation, Browser MCP is 100x faster to boot, consumes ~95% less RAM, batches multi-field forms atomically with browser_fill, and provides 43 automation tools including CDP compositor highlights and failed network telemetry.
Is my browsing data and token security protected?
Yes. Browser MCP contains zero telemetry, zero analytics, and connects strictly over local loopback (127.0.0.1:9876-9895). It enforces strict Origin: chrome-extension://[a-p]{32} verification on incoming WebSockets to prevent unauthorized local process connections. Source code is completely open and auditable on GitHub.
How does CAPTCHA assistance and 2FA work?
When an automated turn encounters a CAPTCHA or 2FA verification challenge, Browser MCP invokes browser_ask_user to render an interactive in-browser dialog. The automation pauses cleanly until you approve or complete the step on your own screen, after which the agent resumes in the exact same tab.
Which AI coding assistants are supported?
Any assistant supporting standard MCP JSON-RPC over stdio works out of the box, including Claude Code, Cursor, Codex, Antigravity, OpenCode, VS Code, and Zed. Run browser-mcp install to automatically configure all detected client configuration files.
